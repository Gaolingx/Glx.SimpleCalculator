## 功能概览

- **7 个页面**：基本、科学型、程序员、统计型、日期计算、单位转换、工作表。
- **基本 / 科学**：表达式优先级与括号、幂右结合、百分比、记忆、退格/CE/C、重复 `=`；科学函数含三角/反三角/双曲、对数、阶乘、随机、`x^y`，DEG/RAD/GRAD 与 F-E 显示。
- **程序员**：QWORD/DWORD/WORD/BYTE 字宽，HEX/DEC/OCT/BIN 同步视图，位运算、移位、循环移位、补码与可点击位网格。
- **统计**：列表式数据集（增删改、排序、清空），求和/均值/中位数/众数/极差/标准差/方差，Kahan 求和。
- **日期**：日期差（年/月/日、总天数、总周数）与日期加减（天/周/月/年，月末夹取、闰年），自定义日历弹层。
- **单位转换**：11 类单位与交叉换算；汇率取自 ECB，24 小时缓存，离线回退并提示缓存日期。
- **工作表**：抵押贷款（等额本息）、油耗（L/100km、mpg US/UK）、租赁；字段级校验、金额两位小数。
- **通用能力**：按模式隔离的历史记录（可配置上限）、系统剪贴板与右键菜单、`F1` 快捷键说明、`Ctrl+H` 历史、`Ctrl+C/V`、数字分组开关。
- **外观与无障碍**：浅色/深色/跟随系统、zh-CN/en-US 即时切换、100–200% DPI、Windows 文本大小 100–150%、键盘全流程、跳转链接、焦点环与图标按钮可访问名称。

## 安装

1. **普通用户（推荐）**：运行 `Glx Calculator_0.1.0_x64-setup.exe`。NSIS 为 `currentUser` 安装，免提权，安装到 `%LOCALAPPDATA%\Glx Calculator`，安装时可选择 English / 简体中文。
2. **管理员集中部署**：MSI 为 `perMachine`，需要管理员权限；提供 en-US / zh-CN 两个包，按系统语言或部署策略选用。
3. **WebView2**：安装包使用 silent `downloadBootstrapper`，需要联网拉取 Runtime；离线机器或 Windows Server 请先预装 Evergreen Runtime，否则安装会失败。

卸载：NSIS 通过「应用和功能」或在安装目录运行 `uninstall.exe`；MSI 通过「应用和功能」卸载。

## 数据来源与合规

- 汇率来自欧洲央行 ECB 每日参考汇率 `https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml`，基准 EUR；界面标注数据来源与数据日期。
- 汇率仅供参考，不构成交易建议；应用不用于金融交易或结算。
- 本地数据仅保存在 `%APPDATA%\com.glx.calculator\`（`settings.json`、`history.json`、`currency-cache.json`、`.window-state.json`），不上传。
